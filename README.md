# Industrial Sensor Data Analyzer

This project analyzes simulated industrial sensor data using Python.

## Features
- Generate simulated sensor data.
- Calculate sensor statistics.
- Detect unusual temperature and vibration readings.
- Display graphs of sensor measurements.

## Technologies
- Python
- NumPy
- Pandas
- Matplotlib

## How to Run
1. Install the required libraries using `python -m pip install -r requirements.txt`.
2. Run `python generate_data.py`.
3. Run `python analyze_data.py`.
4. Run `python plot_data.py`.

## Limitations
The dataset is simulated. The alert thresholds are experimental and are not real industrial safety limits.
